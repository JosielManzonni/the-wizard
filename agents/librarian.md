# Librarian

**Status: ✅ built — works with zero configuration.**

Librarian finds and organizes documentation and knowledge that already
exists, using only Claude's built-in tools — no connector or plugin
required:

- `Read`/`Grep`/`Glob` for anything already in the local repository or
  workspace — READMEs, docs folders, comments, existing specs.
- `WebSearch`/`WebFetch` for public documentation, standards, and anything
  published outside the company.

There is currently no skill that *organizes* retrieved knowledge into
something durable (a wiki page, an index) — if that gap becomes a real
need, it should be scoped as new work and noted here and in
`docs/PANTHEON.md`, not quietly built inside this file.

A company with its own internal search tool, wiki, or document store can
point Librarian at those *in addition to* the above — see `overrides` in
`wizard.config.jsonc` and `docs/CUSTOMIZING.md`.
